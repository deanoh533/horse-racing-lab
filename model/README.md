# 승률 예측 모델 (실제 마사회 데이터 학습)

한국마사회 경주성적 데이터로 **조건부 로짓**(Conditional Logit) 승률 모델을 학습합니다.
경주마다 출전마끼리 비교해 승률을 계산하는 모델로, 경마 예측에서 표준으로 쓰는 방식입니다 (Bolton & Chapman 1986, Benter 1994).

## 준비

```bash
python3 -m venv .venv
.venv/bin/pip install -r model/requirements.txt
cd model
```

## 1. 데이터 받기

[공공데이터포털](https://www.data.go.kr)에서 "한국마사회 경주성적"을 검색합니다. 방법은 둘 중 하나입니다.

- **파일 데이터(CSV)**: 내려받아 `data/raw/`에 넣습니다. 가장 간단합니다.
- **오픈 API**: 활용 신청 후 서비스키를 받아 아래처럼 수집합니다. 요청 주소와 조회 조건 이름은 신청한 API의 명세서에 나와 있습니다.

```bash
export KRA_API_KEY=발급받은_서비스키
python -m hrl.fetch --endpoint <요청 주소> --param <조회조건>=<값> --out ../data/raw/2024-01.csv
```

마사회 데이터의 열 이름(영문 API 키 `rcDate`, `hrName`, `ord` … / 한글 CSV 헤더 `경주일자`, `마명`, `순위` …)은
`hrl/kra.py`의 `COLUMN_ALIASES`에서 표준 형식으로 바꿉니다. 처음 보는 열 이름이 있으면 여기에 추가하면 됩니다.

> 최소 1~2년치(수천 경주)를 권장합니다. 말·기수 기록이 쌓여야 특징이 의미를 가집니다.

### DuckDB 파일이 있는 경우

`race_entries`(출전·결과)와 `races`(경주 정보) 테이블이 있는 DuckDB 파일을 바로 읽습니다.

```bash
python -m hrl.train --duckdb ../data/raw/kra.duckdb/local.duckdb --out out/kra_model.json
python -m hrl.train --duckdb ../data/raw/kra.duckdb/local.duckdb --use-odds
```

순위와 기록이 모두 없는 출전마(출전 취소·제외)와 결과가 없는 예정 경주는 빼고 읽습니다.

## 2. 학습·평가

```bash
python -m hrl.train --csv "../data/raw/*.csv" --out out/model.json
python -m hrl.train --csv "../data/raw/*.csv" --use-odds        # 단승 배당도 특징으로 사용
python -m hrl.train --csv "../data/raw/*.csv" --test-from 2025-01-01
```

날짜순으로 나눠 **마지막 20% 기간을 시험용**으로 남겨 두고, 그 이전 기간으로만 학습합니다.
결과로 특징별 영향, 시험 기간 성능(시장 배당·찍기와 비교), 보정표를 출력하고 모델을 JSON으로 저장합니다.

## 특징 (모두 경주 '전'에 알 수 있는 정보만 사용)

| 특징 | 설명 |
| --- | --- |
| 말 승률·입상률 | 이전 출전 기록 (출전이 적으면 평균 쪽으로 평활) |
| 최근 5경주·직전 경주 착순 | 착순 백분위 (0 = 1위) |
| 최근 3경주 기록 차 | 우승마 대비 1000m당 늦은 초 |
| 출전 경험, 첫 출전, 휴양 기간 | |
| 기수·조교사 승률 | 경주일 **전날까지** 누적 |
| 레이팅·부담중량·나이 | 같은 경주 평균 대비 |
| 마체중 변화폭, 게이트 위치 | |
| 막판 200m 속도 | 최근 3경주, 같은 경주 평균 대비 |
| 초반 위치 | 최근 5경주 출발 후 200m 지점 순위 (선행형/추입형) |
| 과거 인기 순위 | 최근 3경주에서 시장이 매긴 인기 (이번 경주 배당은 쓰지 않음) |
| 등급 이동 | 직전 경주 대비 1착 상금 비율 |
| 거리 변화, 같은 거리 착순, 휴양 구간, 암말 | |
| 기수·조교사 최근 60일 승률 | 전날까지 |
| 시장 평가 (`--use-odds`) | 단승 배당에서 계산한 승률 |

열이 없는 데이터라면 해당 특징은 자동으로 빠집니다.

## 평가 지표 읽는 법

- **로그손실**: 실제 우승마에 준 확률이 높을수록 낮아짐. 확률 예측의 핵심 지표
- **브라이어 점수**: 모든 말의 (예측 − 실제)² 합. 낮을수록 좋음
- **1위 적중률**: 예측 1위가 실제로 우승한 비율
- **보정표**: "20% 승률로 예측한 말들이 실제로 20% 정도 이겼는가"
- **시장 배당**과 비교: 실제 경마에서 시장(배당)은 매우 강한 예측자입니다. 배당 없이 시장을 이기기는 어렵고,
  `--use-odds`로 배당과 모델 정보를 합쳐 시장보다 나아지는지가 실전적인 목표입니다.

## 실제 데이터 결과 (2022-01 ~ 2026-09, 서울·부산경남·영천 8,201경주)

2025-10-17 이후 1,653경주를 학습에 쓰지 않고 시험했습니다.

| | 로그손실↓ | 1위 적중률↑ |
| --- | --- | --- |
| 찍기 (1/n) | 2.360 | 9.5% |
| 이 모델 (배당 없음) | 1.924 | 32.1% |
| 기존 모델 v6·v7 (`predictions` 테이블) | 1.922 | 32.4% |
| 시장 배당 | 1.759 | 38.8% |
| 이 모델 + 배당 (`--use-odds`) | 1.754 | 38.7% |

- 배당 없는 모델은 기존 모델과 차이가 유의하지 않습니다 (경주 부트스트랩 95% 구간 −0.013 ~ +0.017).
- 배당을 합치면 시장보다 조금 낫지만 (−0.005) 95% 구간이 0에 걸쳐 있어 아직 확실하지 않습니다.
- 데이터의 `win_odds`는 확정 배당이라 실제 베팅 시점의 배당과 다를 수 있습니다.

## 합성 데이터로 시험하기

실제 데이터가 없을 때 파이프라인이 동작하는지 확인하는 용도입니다. **실제 경주 기록이 아닙니다.**

```bash
python -m hrl.sample --out ../data/sample/synthetic_kra.csv
python -m hrl.train --csv ../data/sample/synthetic_kra.csv

```
