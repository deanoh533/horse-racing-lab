# horse-racing-lab

경마 경주 시뮬레이션 + 결과 시각화 대시보드 (TypeScript · Vite · Chart.js)

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 시뮬레이션 엔진 단위 테스트
npm run build    # 타입체크 + 프로덕션 빌드 (dist/)
```

## 기능

- **경주 애니메이션**: 타원형 트랙 위에서 말들이 반시계 방향으로 달리고, 실시간 순위표가 갱신됩니다 (1x–8x 재생, 즉시 결과).
- **경주 결과**: 순위, 기록, 1위와의 차이, 평균 속도, 구간별 속도 그래프.
- **몬테카를로 분석**: 같은 조건으로 N회(최대 20,000회) 반복해 승률, 3위 이내 입상률, 순위 분포, 평균 순위·기록, 적정 배당(1/승률)을 계산합니다. Web Worker에서 돌기 때문에 UI가 멈추지 않습니다.
- **출전마 편집**: 시드로 출전마를 무작위 생성하고, 능력치는 표에서 바로 수정할 수 있습니다.

## 시뮬레이션 모델 (`src/sim/race.ts`)

0.1초 단위로 각 말의 속도와 위치를 갱신합니다.

| 능력치 | 효과 |
| --- | --- |
| 최고속도 (m/s) | 목표 속도의 기준 |
| 지구력 | 체력 총량. 체력이 25% 아래로 떨어지면 감속 (장거리에서 중요) |
| 가속력 | 목표 속도에 도달하는 빠르기 |
| 안정성 | 당일 컨디션과 경주 중 컨디션 변동 폭 (낮을수록 이변이 잦음) |
| 불량주로 적응력 | 다습·불량 주로에서의 감속 폭을 최대 70% 줄여 줌 |

- 페이스 전략: 최고속도의 92%로 순항하다가 남은 거리 400m부터 전력 질주
- 체력 소모는 (현재 속도 / 최고속도)³에 비례
- 시드 기반 난수(mulberry32)를 쓰므로 같은 시드면 같은 경주가 재현됩니다
- 기록은 실제 경마와 비슷하게 맞췄습니다 (1600m 약 1:35–1:41)
